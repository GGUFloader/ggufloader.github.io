🎨 Instagram Floating Button Demo

👀 Look at the bottom-right corner!

You should see a beautiful Instagram button floating in the bottom-right corner of this page. This button will appear on all blog posts.

✨ Features

  • Links to @nazary.ai on Instagram
  • Gradient colors matching Instagram branding
  • Responsive: shows icon + text on desktop, icon only on mobile
  • Smooth animations: slide-in effect and subtle pulse
  • Fully accessible: keyboard navigation, ARIA labels, focus states
  • Analytics tracking ready (Google Analytics & Plausible)

📱 Responsive Behavior

Desktop: Shows full button with icon and text

Tablet: Slightly smaller but still shows text

Mobile (< 480px): Circular button with icon only

Try resizing your browser window to see the responsive behavior!

🔧 Implementation

Only two lines needed in the <head> section:

<link rel="stylesheet" href="css/instagram-float-button.css"> <script src="js/instagram-float-button.js" defer></script>

⚙️ How It Works

  1. The JavaScript file automatically initializes when the page loads
  2. It creates the button element and appends it to the body
  3. The button includes an Instagram icon (SVG) and text
  4. CSS handles all styling, animations, and responsive behavior
  5. No manual HTML needed - it's completely automatic!
